# GitFlow Project

Este es un proyecto de ejemplo que implementa la metodología **Git Flow** para el manejo de ramas y versiones.

## 📦 Estructura de ramas

- `main`: Rama principal, versión en producción.
- `develop`: Rama de desarrollo activo.
- `feature/*`: Nuevas funcionalidades.
- `release/*`: Versiones candidatas a producción.

git clone git@github.com:FranciscoRosa-UCA/GitFlow.git
